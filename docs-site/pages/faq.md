# FAQ & troubleshooting

Each entry is a **routing answer**: it tells you which canonical section governs
the question. This page deliberately does not restate support, save, recovery,
permission, or capability statements; those facts live only in the projected
pages, and the canonical page governs if anything here disagrees. Error codes,
unsupported fixes, and unverified workarounds are intentionally absent.
