# 概览

Exam 是通用考试与测评平台。其受支持的部署形态、适用性、单组织边界与语言
边界见 [Standard 能力说明 §1–§2](/zh/standard/capabilities#_1-适用性-applicability)。
本页只是路由页，不重述产品保证。

## Standard 当前支持什么？

权威答案是版本绑定的[支持与证据矩阵](/zh/standard/capabilities#_8-支持与证据矩阵)。
本页不做概括：矩阵逐行给出产品状态、前提、适用版本、证据类型、规范来源与
限制。

## 已知限制是什么？

请阅读[明确不保证项](/zh/standard/capabilities#_7-明确不保证项)与
[适用性章节](/zh/standard/capabilities#_1-适用性-applicability)。限制只在这两处
陈述。

- **考生** —— 考生步骤见[操作指南](/zh/guide/first-exam#_9-考生-登录并开始)。
- **教师 / 阅卷人** —— 人工评分流程见
  [操作指南](/zh/guide/first-exam#_12-人工评分-仅当本场含文本作答题)。
- **部署方 / 运维** —— 部署、备份、恢复与故障域材料见[可靠性与运维](/zh/reliability)。
