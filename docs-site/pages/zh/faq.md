# 常见问题

每条都是**路由式回答**：告诉你哪个规范章节负责该问题。本页刻意不重述支持、
保存、恢复、权限或能力陈述；这些事实只存在于投影页面中，若此处与规范页面
不一致，以规范页面为准。本页不编造错误码、未支持的修复步骤或未经验证的
绕过方法。
