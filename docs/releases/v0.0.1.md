# v0.0.1

`v0.0.1` is the first formal repository release baseline for Exam.

It captures the project after completion of the S0 simplification and
PostgreSQL/test-infrastructure convergence work. The generic product roadmap is
still in progress under Issue #333; this release is therefore a pre-1.0
baseline rather than a feature-complete product claim.

## Highlights

- Generic exam workflows already present in the repository are captured under a
  stable version tag for the first time.
- Candidate result-visibility policy is closed across candidate-facing
  projections.
- PostgreSQL test ownership is explicit: operator-owned explicit databases,
  harness-owned implicit local `exam_test`.
- Vitest worker resources are bounded by execution slots (`VITEST_POOL_ID`).
- Worker-database runs have explicit cluster-scoped ownership and deterministic
  inter-file reset semantics.
- Obsolete worker-database sweep/initdb compensation paths were removed after
  their root causes were fixed.
- Turbo routing/cache identity now follows test-topology inputs.
- The remaining file-schema P1-3 fixture defect was fixed without changing
  product semantics.

## Verification baseline

The release-preparation commit is documentation-only. The immediately preceding
product/test baseline on `master` is merge commit `de95b6f1`, which closed the
S0 residual test issue after exact-head CI, targeted isolation matrices, cold
verification, and E2E validation.

See `CHANGELOG.md` for the canonical release-history entry.
