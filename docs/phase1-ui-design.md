# Phase 1 UI Design

> 所有界面遵循 shadcn/ui 设计系统 + TailwindCSS v4。
> 用户界面文字全部中文，以下 wireframe 中的中文即为实际 UI 文案。

---

## 1. Design Tokens

### Color Palette (shadcn/ui neutral base)

```
Primary:     用于主按钮、活跃导航、链接
Destructive: 用于删除、警告、未通过
Muted:       用于背景、禁用状态、次要文字
Accent:      用于 hover、选中态
Border:      用于分割线、边框
Background:  页面背景 / 卡片背景 / 弹窗背景
```

不使用紫色/渐变。主色调跟随 shadcn 默认 neutral 方案，干净专业。

### Typography

```
页面标题:    text-2xl font-semibold
区域标题:    text-lg font-medium
正文:        text-sm
次要文字:    text-sm text-muted-foreground
标签/辅助:   text-xs text-muted-foreground
```

### Spacing

统一使用 Tailwind spacing scale: `p-4`(16px), `gap-4`(16px), `p-6`(24px)。不使用非标准值。

## 2. Navigation Structure

### 2.1 Layout Tree

```
/ (redirect to role-based dashboard)
├── /login                          # 登录页（全屏，无侧栏）
│
├── /admin/*                        # Admin/Teacher 共享后台
│   ├── Layout: Sidebar + Header
│   ├── /admin/dashboard            # 仪表盘
│   ├── /admin/organizations        # 机构管理（SuperAdmin）
│   ├── /admin/users                # 用户管理（Admin/Teacher/Proctor）
│   ├── /admin/candidates           # 考生管理（动态字段表格）
│   ├── /admin/candidate-fields     # 考生字段配置
│   ├── /admin/courses              # 课程管理
│   ├── /admin/questions            # 题库管理
│   ├── /admin/questions/new        # 新建题目
│   ├── /admin/questions/:id/edit   # 编辑题目
│   ├── /admin/questions/import     # 批量导入题目
│   ├── /admin/exams                # 考试管理
│   ├── /admin/exams/new            # 新建考试（组卷）
│   ├── /admin/exams/:id            # 考试详情（考生列表+状态）
│   ├── /admin/exams/:id/scores     # 成绩管理
│   ├── /admin/papers/:id           # 答卷详情（Teacher 视角）
│   └── /admin/system               # 系统健康
│
└── /exam/*                         # 考生端（独立布局）
    ├── Layout: Fullscreen, minimal
    ├── /exam/list                  # 可参加的考试列表
    ├── /exam/:id/start             # 开始考试确认页（含排队）
    ├── /exam/:id/take              # 答题界面（全屏）
    └── /exam/:id/result            # 考试结果（双态：即时出分/等待公布）
```

## 5. Interaction Patterns

### 5.1 自动保存

答题时，每次选择/输入变更后:
1. 输入框旁显示灰色 `保存中...` → 绿色 `✓ 已保存`
2. 保存失败显示红色 `⚠ 保存失败，正在重试...`
3. 使用去抖（1-2s），避免每次按键都请求

### 5.2 倒计时

- 服务端返回 `startedAt` + `durationMinutes`，客户端计算剩余时间
- 每 30s 向服务端同步一次（校正漂移）
- `< 5min` 时倒计时文字变红
- `= 0` 时自动交卷，弹窗提示"考试时间已到"

### 5.3 表单验证

- 使用 react-hook-form + zod
- 实时校验 + 提交时校验
- 错误提示在字段下方，红色文字

### 5.4 Toast 通知

- 成功: 绿色 toast，3s 自动消失
- 错误: 红色 toast，需手动关闭
- 警告: 黄色 toast，5s 自动消失

## 6. Empty / Error / Loading States

每个列表页都必须处理三种状态:

```tsx
// Loading: 骨架屏
<Skeleton className="h-10 w-full" />

// Empty: 提示 + 引导操作
<EmptyState
  icon={<QuestionsIcon />}
  title="暂无题目"
  description="点击上方按钮创建第一道题目"
  action={<Button>新建题目</Button>}
/>

// Error: 错误提示 + 重试
<ErrorState message="加载失败" onRetry={refetch} />
```
