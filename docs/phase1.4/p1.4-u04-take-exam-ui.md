# P1.4-U04 Take Exam UI Notes

## 页面结构

- 顶部状态栏：显示当前答题状态、题目进度、保存状态、倒计时和交卷入口。
- 题号导航：宽屏为侧栏，1024px 及以下为横向可滚动题号条，避免压缩答题区。
- 答题区：使用单一主面板承载题干、分值、标记按钮和答题控件，保持阅读优先。
- 底部操作栏：固定上一题、标记、下一题/提交考试操作，并展示已答、未答、标记统计。

## 状态反馈

- 倒计时剩余 5 分钟及以内进入红色警示样式。
- 保存状态始终保留稳定占位：等待保存、保存中、已保存、保存失败都有图标和颜色差异。
- 加载失败显示可重试错误态。
- 答案保存或心跳失败显示连接异常提示，不改变 Answer Save Protocol 或提交协议。

## 交互边界

- 本次只调整视觉、布局和反馈。
- 未实现 submit flush；该行为归 S03b。
- 未修改 answer save protocol、submit API protocol、attempt status state machine 或 deadline 行为。
- 未引入动画库、全屏模式或监考行为。
