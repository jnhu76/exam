## Key Decisions

1. **`isSqlite(db)` + `as SqliteDatabase | PostgresDatabase`**: After the type guard narrows, we cast to the specific dialect type. This avoids `as unknown as` while still being type-safe.

2. **`TenantTablePair`**: Each repo receives a `{ sqlite, pg }` pair of table references. The `createAsyncTenantCrudRepo` factory uses `isSqlite(db)` to select the correct table.

3. **`create()` re-queries instead of casting**: The `create` method in `baseRepo.ts` inserts the row then calls `findById` to get the properly typed result. This eliminates `as unknown as Select` at the cost of an extra query, which is acceptable for correctness.

4. **Seed files accept `AnyDatabase` with `isSqlite()` guard**: Both `seed.ts` and `demo-seed.ts` accept `AnyDatabase` and throw if not SQLite. This is correct since seed is a dev/demo-only utility. The guard uses `isSqlite()` from `types.ts`, and after narrowing, assigns to a locally typed `const db: SqliteDatabase` so closures get proper types.

5. **Repository interfaces accept `Promise | sync`**: The `ExamRepository`, `AttemptRepository`, `EnrollmentRepository` interfaces in `exam-engine` accept both `Promise<T>` and `T` returns. This allows test mocks to remain synchronous while production adapters return Promises.
