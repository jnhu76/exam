## 管理员操作

### 创建组织

**前置条件**: 首次使用系统，尚未创建组织

**步骤**:

1. 访问系统首页，点击"创建组织"
2. 填写组织信息：
   - 组织名称: 如"考试中心"
   - 组织标识: 如"exam-center"（URL 友好）
   - 产品名称: 如"考试平台"
   - 产品副标题: 如"可靠的内网考试系统"
   - 页脚文本: 如"© 2024 某机构"
3. 点击"创建"
4. 系统自动创建管理员账号：
   - 用户名: `admin`
   - 密码: 临时密码（登录后需修改）
5. 使用管理员账号登录系统

**注意事项**:
- 组织标识创建后不可修改
- 临时密码仅首次登录有效，请立即修改

### 配置字段

**场景**: 自定义考生身份字段（如学号、姓名、院系、年级）

**步骤**:

1. 登录系统 → 进入"设置" → "考生字段"
2. 点击"添加字段"
3. 填写字段信息：
   - 字段名称: 如 `studentId`
   - 字段标签: 如"学号"
   - 字段类型: 文本 / 下拉框
   - 是否必填: ✓
   - 是否唯一: ✓
   - 排序: 0
4. 点击"保存"
5. 重复步骤 2-4，添加其他字段（姓名、院系、年级）
6. 点击"下载模板"获取 CSV 导入模板

**示例字段配置**:

| 字段名称 | 字段标签 | 字段类型 | 必填 | 唯一 | 排序 |
|---------|---------|---------|------|------|------|
| studentId | 学号 | 文本 | ✓ | ✓ | 0 |
| name | 姓名 | 文本 | ✓ | ✗ | 1 |
| department | 院系 | 文本 | ✓ | ✗ | 2 |
| grade | 年级 | 文本 | ✓ | ✗ | 3 |

**注意事项**:
- 字段名称使用英文，字段标签使用中文
- 排序决定导入模板中的列顺序
- 唯一字段不能重复（如学号）

### 批量导入考生

**前置条件**: 已配置考生字段，已下载模板

**步骤**:

1. 准备 CSV 文件（使用模板，UTF-8 编码）
2. 打开"考生管理"页面
3. 点击"导入考生"
4. 上传 CSV 文件
5. 系统显示验证结果：
   - 总行数: 10
   - 新建: 8
   - 更新: 2
   - 错误: 0
6. 点击"确认导入"

**示例 CSV 内容**:
```csv
学号,姓名,院系,年级
20240001,张三,计算机系,2024级
20240002,李四,软件工程,2024级
20240003,王五,信息安全,2023级
```

**错误处理**:

| 错误信息 | 解决方法 |
|---------|---------|
| Missing required fields | 检查必填字段是否填写 |
| StudentId already exists | 修改重复的学号 |
| Invalid CSV format | 使用 UTF-8 编码，检查列分隔符 |

**注意事项**:
- 重复导入会更新已有考生信息（根据唯一标识）
- 未提供密码时，默认密码为 123456
- 导入后考生可使用 `username` + 密码登录

### 创建课程

**步骤**:

1. 进入"课程管理"页面
2. 点击"新建课程"
3. 填写课程信息：
   - 课程名称: 如"数学基础"
   - 课程代码: 如"MATH101"
   - 课程描述: 如"高等数学入门课程"
4. 点击"保存"

**注意事项**:
- 课程代码在组织中必须唯一
- 试题归属于课程，考试归属于课程

### 批量导入试题

**前置条件**: 已创建课程

**步骤**:

1. 准备 CSV 文件（见 `docs/import-export-format.md` 中的格式说明）
2. 进入"试题管理" → 选择课程 → 点击"导入试题"
3. 上传 CSV 文件
4. 系统显示验证结果：
   - 总行数: 50
   - 有效: 48
   - 警告: 2
   - 错误: 0
5. 点击"确认导入"

**示例 CSV 内容** (单选题):
```csv
type,content,optionA,optionB,optionC,optionD,standardAnswer,score,difficulty,tags
single_choice,下列哪个是质数？,2,3,5,7,B,5,3,数学 基础
single_choice,1+1=?,1,2,3,4,B,5,2,数学 基础
```

**错误处理**:

| 错误信息 | 解决方法 |
|---------|---------|
| choice questions require at least two options | 确保选择题至少有 2 个选项 |
| standardAnswer must be a valid option id | 确保标准答案引用了有效的选项 id |
| fill_blank questions must contain at least one placeholder | 确保填空题包含 `____` 占位符 |

**注意事项**:
- 题目类型: single_choice, multiple_choice, fill_blank, true_false
- 标准答案: 选择题用选项 id，填空题为文本，判断题为布尔值
- 分值: 正整数
- 难度: 1-5

### 创建考试

**前置条件**: 已创建课程，已导入试题

**步骤**:

1. 进入"考试管理" → 点击"新建考试"
2. 填写考试信息：
   - 考试名称: 如"数学基础考试"
   - 所属课程: 选择课程
   - 考试时长: 60 分钟
   - 开放时间: 2024-06-01 09:00
   - 结束时间: 2024-06-01 11:00
   - 及格分数: 60 分
3. 配置题目：
   - 选择题目模式: 手动选择 / 随机抽取
   - 选择题目: 从试题库中勾选题目
   - 查看总分: 系统自动计算
4. 配置控制策略：
   - 题目顺序: 打乱 / 原序
   - 选项顺序: 打乱 / 原序
   - 检测切屏: 开启 / 关闭
   - 禁止复制粘贴: 开启 / 关闭
   - 队列入场: 开启 / 关闭
   - 队列批次: 10 人
   - 批次间隔: 3 分钟
   - 限制 IP: 开启 / 关闭
   - 锁定浏览器: 开启 / 关闭
   - 即时显示结果: 开启 / 关闭
5. 配置重考策略：
   - 重考策略: 不允许重考 / 限制次数 / 无限重考
   - 成绩策略: 最高分 / 最新成绩 / 首次成绩
   - 最大尝试次数: 1 次
6. 点击"保存"

**注意事项**:
- 题目分数总和即为考试总分
- 队列入场适用于大批量考试（如 500+ 考生）
- 重考策略和成绩策略联合使用

---

### 发布考试

**前置条件**: 已创建考试

**步骤**:

1. 进入"考试管理" → 选择考试 → 点击"发布"
2. 勾选考生：
   - 从考生列表中勾选需要参加考试的考生
   - 点击"全选"快速选择所有考生
   - 搜索考生: 按学号、姓名等字段搜索
3. 查看已选考生数量
4. 点击"发布"

**发布后状态**:
- 考生可在"我的考试"中查看
- 考生可在开放时间内开始考试
- 考试时间到期后自动关闭

**注意事项**:
- 发布后的考试不能修改题目
- 发布后可以调整考生名单（添加/移除）

---

### 导出成绩

**前置条件**: 考试已结束，考生已提交

**步骤**:

1. 进入"考试管理" → 选择考试 → 点击"导出成绩"
2. 系统自动生成 CSV 文件并下载
3. 打开 CSV 文件查看成绩

**CSV 内容示例**:
```csv
考生姓名,学号,院系,年级,成绩,及格状态,尝试次数,提交时间
张三,20240001,计算机系,2024级,85,及格,1,2024-06-01T10:05:00.000Z
李四,20240002,软件工程,2024级,72,不及格,2,2024-06-01T10:08:00.000Z
```

**注意事项**:
- 导出的成绩是最终成绩（由成绩策略决定：最高分 / 最新成绩 / 首次成绩）
- 列标题根据组织配置的 CandidateField 动态生成
- 支持大文件导出（500+ 考生）

## 考生操作

### 登录系统

**步骤**:

1. 访问系统首页
2. 输入用户名（学号 / 工号）
3. 输入密码
4. 点击"登录"

**首次登录**:

- 登录后立即修改密码（进入"我的设置" → "修改密码"）

### 查看我的考试

**步骤**:

1. 登录系统
2. 进入"我的考试"
3. 查看考试列表：
   - 考试名称
   - 所属课程
   - 状态: 未开始 / 进行中 / 已完成
   - 开放时间 / 结束时间
   - 我的成绩
4. 点击考试进入详情页

---

### 参加考试

**前置条件**: 考试状态为"进行中"

**步骤**:

1. 进入"我的考试" → 选择考试 → 点击"开始考试"
2. **排队入场**（如开启队列）:
   - 等待页面显示当前排队人数
   - 等待页面显示预计等待时间
   - 到达批次后自动跳转至考试页面
3. **开始考试**:
   - 查看考试剩余时间（倒计时）
   - 浏览题目（左侧题目导航）
   - 回答题目（单选题、多选题、填空题、判断题）
   - 查看答题进度（已答题数 / 总题数）
4. **提交考试**:
   - 答完所有题目后点击"提交"
   - 确认提交对话框：显示已答题数 / 总题数
   - 点击"确认提交"
5. **查看成绩**（如即时显示结果）:
   - 显示总分
   - 显示及格状态
   - 显示各题得分

**注意事项**:
- 系统自动保存答案（每 5 秒或每次修改答案）
- 切换标签页会被检测（如开启检测）
- 复制粘贴会被禁止（如开启禁止）
- 倒计时结束自动提交
- 提交后不能修改答案

---

### 查看成绩

**步骤**:

1. 进入"我的考试"
2. 查看考试列表中的"我的成绩"列
3. 点击考试进入详情页

**注意事项**:
- 成绩由成绩策略决定（最高分 / 最新成绩 / 首次成绩）
- 多次考试时显示最终成绩

## 常见问题

### Q: 如何修改考生密码？

A: 管理员无法修改考生密码，考生需自行登录系统后进入"我的设置" → "修改密码"。

### Q: 如何重考？

A: 重考由重考策略决定：
- 不允许重考: 无法再次参加
- 限制次数: 在最大尝试次数内可重考
- 无限重考: 无限制重考

### Q: 如何查看我的答题情况？

A: 提交考试后进入"我的考试" → 点击考试 → 查看成绩详情（显示各题得分）。

### Q: 考试过程中断网了怎么办？

A: 系统会自动保存答案到本地，网络恢复后自动同步到服务器。如超时未同步，可刷新页面恢复答案。

### Q: 考试倒计时结束但未提交怎么办？

A: 系统自动提交当前答案，无需手动操作。

### Q: 如何导入大批量考生？

A: 使用 CSV 批量导入，支持 1000+ 考生。确保 CSV 文件使用 UTF-8 编码，列标题与字段配置一致。

### Q: 如何删除考试？

A: 考试发布后无法删除，可以修改状态为"已结束"。

### Q: 如何修改考试题目？

A: 考试发布后无法修改题目，如需修改请撤销发布后重新发布。

### Q: 如何查看考生切屏次数？

A: 切屏检测仅用于警告，不记录次数。如开启检测，切屏时会弹出警告提示。

### Q: 如何导出成绩到 Excel？

A: 点击"导出成绩"按钮下载 CSV 文件，用 Excel 或 WPS 打开即可。

### Q: 如何限制考试 IP？

A: 在创建考试时开启"限制 IP"，并填写允许的 IP 地址列表（如 192.168.1.0/24）。

### Q: 如何使用队列入场？

A: 在创建考试时开启"队列入场"，设置批次大小和批次间隔。考生进入考试时会显示排队状态，批次到达后自动跳转。
